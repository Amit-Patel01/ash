# Project Structure

## `backend/`
- `server.js`: Central Express app.
- `uploads/`: Media files (categorized by source).
- `credentials.json`: Firebase Admin configuration.
- `package.json`: Backend dependencies.

## `frontend/`
- `src/`: Main source code.
  - `admin/`: Components for the Admin area.
  - `components/`: Generic UI components.
  - `pages/`: Page-level components.
  - `config/`: Config files (API URLs).
  - `index.css`: Tailwind CSS entry.
- `vite.config.js`: Build configuration.
- `package.json`: Frontend dependencies.
