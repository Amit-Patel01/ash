# Testing Strategy

## Automatic Testing
- No automated testing suites (Jest, Mocha, Cypress) found in `package.json`.

## Manual Testing
- Postman or browser-based API testing for endpoints.
- UI validation for logic (Admin, User flows).

## Verification Plan
- Cross-browser compatibility check.
- Mobile responsiveness check via dev tools.
- API response validation (Resend, Razorpay).
