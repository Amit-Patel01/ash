# Integrations

## Core Services
- **Firebase**: Backend authentication and Firestore data.
- **Razorpay**: E-commerce payment gateway.
- **Resend**: Transactional emails (e.g., payment confirmation, password reset).
- **Svix**: Likely used for webhooks.

## Media Handling
- **Multer**: Backend library for receiving multipart/form-data (uploads).
- **Local Storage**: `uploads/` directory on the server filesystem.
