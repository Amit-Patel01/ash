# Tech Stack

## Backend
- **Core**: Node.js (Express)
- **Database/Auth**: Firebase Admin SDK
- **Payments**: Razorpay
- **Emails**: Resend, Nodemailer
- **File Handling**: Multer (Local storage)
- **Scheduling**: Node-cron

## Frontend
- **Core**: Vite + React
- **Styling**: Tailwind CSS, Framer Motion
- **Icons**: Lucide-React
- **Routing**: React Router DOM
- **Interactions**: Firebase Client SDK
- **Utilities**: html-to-image, jspdf, qrcode.react
